# Packet Panic

An infrastructure simulator built with React, TypeScript, Vite, Tailwind and lucide-react.
Scale a backend with Redis caching, queues and workers while traffic grows, and watch the
database utilization, latency and error rate respond.

Served at `/packet-panic/` on the lab domain. From the repository root:

```sh
npm run dev:packet-panic
npm run build:packet-panic
```
